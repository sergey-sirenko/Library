# Руководство по репозиторию

## Перед началом задачи

- Сразу прочитайте `memory-bank/activeContext.md`: он содержит текущее состояние
  и указывает, какие дополнительные файлы Memory Bank нужны для конкретной задачи.
- Не загружайте весь Memory Bank без необходимости. Проверяйте его утверждения по
  коду, конфигурации, тестам и фактическому состоянию Git.
- Общайтесь с пользователем и ведите документацию на русском языке.

## Согласование и границы

- Перед редактированием опишите предполагаемые изменения и получите явное
  согласие. После согласования выполняйте задачу целиком в одобренных границах.
- Сохраняйте чужие и runtime-изменения рабочего дерева: не удаляйте, не
  откатывайте, не исправляйте и не добавляйте их в коммит без разрешения.
- Не изменяйте пользовательские `Data`, `Covers`, `Backup`, `Logs` и их варианты
  внутри `Prog/`, если задача прямо этого не требует.
- Не коммитьте EXE, `Library.exe.old`, runtime-копии `INSTALL.md`, данные,
  журналы, резервные копии и содержимое `lib/` или `dist/`.
- Не выполняйте `git push`, не создавайте и не отправляйте теги и не создавайте
  GitHub Releases без отдельного явного указания пользователя.
- Не записывайте в документацию секреты и реальные данные библиотеки.

## Выполнение и завершение

- Для изменений проекта следуйте `memory-bank/developmentWorkflow.md`, а команды
  и проверки выбирайте по `memory-bank/techContext.md`.
- Не запускайте основное приложение и не автоматизируйте проверку его интерфейса.
  Только соберите проект и передайте результат пользователю для ручной проверки;
  отдельные автоматические тестовые проекты при этом запускать можно.
- Процесс публикации загружайте только для соответствующей задачи из
  `memory-bank/releaseProcess.md`.
- После одобренной реализации пересмотрите только связанные файлы Memory Bank и
  обновите их, если факты действительно изменились. Не превращайте их в журнал
  истории: история хранится в Git.
- Перед завершением сообщите, что изменено, какие проверки выполнены и какие
  ограничения или незавершённые действия остались.
