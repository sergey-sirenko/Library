# Контекст продукта

## Зачем нужна система
Библиотекарю и администратору храма нужен локальный учёт фонда и выдач без интернета и без установки СУБД.

## Как должна работать
1. Пользователь входит по логину/паролю.
2. Ведёт каталог книг и экземпляров с инвентарными номерами.
3. Регистрирует читателей, выдаёт/возвращает/продлевает книги.
4. Видит просрочки, отчёты и журнал действий.
5. Создаёт и восстанавливает резервные копии каталога `Data`.

## UX-цели
- Понятные русские сообщения об ошибках.
- Подтверждение удаления/восстановления.
- Скрытие логически удалённых записей в обычном режиме.
