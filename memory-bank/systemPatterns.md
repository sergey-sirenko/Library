# Системные паттерны

## Архитектура
- Слой данных: загрузка `.dat` в память при старте.
- Слой сервиса: `TLibraryDB` — CRUD, бизнес-правила, индексы, журнал.
- UI: формы Lazarus (вход + главная с вкладками разделов).

## Безопасная запись
Временный файл → проверка → замена рабочего файла → повторная проверка.

## Идентификаторы
Внутренние `ID` не показываются пользователю; связи только через ID.

## Удаление
Только логическое (`Deleted`, `DeletedAt`, `DeletedBy`).

## Индексы
Нормализованный ключ + ID; перестроение при повреждении.

## Внешние сервисы
- Только встроенные в Windows API. Сторонних DLL нет.
- HTTPS — через WinHTTP (`WinHttpOpen`/`WinHttpConnect`/`WinHttpOpenRequest` + `WINHTTP_FLAG_SECURE`); SChannel под капотом, в `Library.exe` зависимость только от `winhttp.dll` и стандартных системных.
- Не использовать `fphttpclient` + `opensslsockets`: требует рантайм-DLL, которые в проекте не поставляются.
