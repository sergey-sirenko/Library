# Краткое описание проекта

## Название
Информационная система «Библиотека храма» (Library).

## Цель
Настольное приложение для учёта книг, экземпляров, читателей и выдач библиотеки храма без внешней СУБД.

## Ключевые требования
- Free Pascal / Lazarus, только стандартные возможности.
- Собственное бинарное файловое хранилище (`Data\*.dat`) и индексы (`*.idx`).
- Автонумерация ID, логическое удаление, журнал действий.
- Безопасная запись, резервное копирование, одноэкземплярный доступ к данным.
- Русскоязычный интерфейс.
