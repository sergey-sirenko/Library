# Краткое описание проекта

## Название и цель

Информационная система «Библиотека храма» (Library) — настольное Windows-
приложение для локального учёта книг, экземпляров, читателей и выдач без внешней
СУБД.

## Ключевые требования

- Free Pascal / Lazarus и стандартные компоненты Windows/FPC.
- Собственное бинарное хранилище `Data\*.dat` и индексы `*.idx`.
- Автонумерация ID, логическое удаление, журнал действий и одноэкземплярный
  доступ к данным.
- Безопасная запись и резервное копирование до потенциально опасных операций.
- Русскоязычный интерфейс; основная библиотечная работа доступна без интернета.
- Опциональные сетевые функции: OpenRouter и ручное обновление через стабильные
  GitHub Releases.
