# Процесс разработки

## До изменений

1. Прочитайте `AGENTS.md`, `activeContext.md` и только связанные с задачей файлы.
2. Проверьте первичные источники: код, конфигурацию, тесты и `git status`.
3. Отделите изменения текущей задачи от уже существующих изменений рабочего дерева.
4. Опишите пользователю предполагаемое решение и получите явное согласие на
   редактирование.

## Реализация

- Меняйте только согласованные файлы и не расширяйте область задачи без нового
  согласования.
- Сохраняйте форматы данных и архитектурные инварианты из `systemPatterns.md`.
- Object Pascal оформляйте в режиме `{$mode objfpc}{$H+}` с отступом в два
  пробела; `begin` и `end` размещайте на отдельных строках, при ошибках
  предпочитайте ранний выход.
- Модули называйте с префиксом `u`, типы — с `T`, константы — в
  `UPPER_SNAKE_CASE`. Тексты интерфейса и документация должны быть на русском.
- Не исправляйте попутно несвязанные проблемы. Найденный существенный дефект
  зафиксируйте в отчёте или согласуйте отдельную работу.

## Проверка

1. Выберите проверки по матрице из `techContext.md`.
2. После изменения кода соберите затронутый проект и убедитесь в `0 errors`.
3. Для UI и сценариев без автотестов выполните целевую ручную проверку.
4. Выполните `git diff --check` и повторно проверьте `git status`.

## Документация и Memory Bank

- Обновляйте только файлы, факты в которых изменились вследствие реализации.
- `activeContext.md` хранит текущий фокус, проверки, блокеры и известное состояние,
  а не историю завершённых задач.
- `progress.md` хранит карту возможностей и актуальный бэклог; подробная история
  изменений остаётся в Git.
- Связанную документацию включайте в тот же тематический набор изменений, что и код.

## Git и критерии завершения

- Перед коммитом добавляйте в индекс только файлы текущей задачи.
- Если создаётся локальный коммит, он должен быть коротким, тематическим и иметь
  русское сообщение в повелительной форме.
- Задача завершена, когда реализован согласованный результат, выполнены доступные
  проверки, документация синхронизирована, а пользователю сообщены результат,
  проверки и оставшиеся ограничения.
