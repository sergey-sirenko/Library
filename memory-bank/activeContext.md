# Активный контекст

Этот файл читается после `AGENTS.md`: здесь актуальное состояние и маршруты.
Код и Git имеют приоритет.

## Маршрут по типу задачи

| Задача | Что прочитать |
|---|---|
| Цель, границы или источник требований | `projectbrief.md` |
| Поведение, пользовательский сценарий или UI | `productContext.md` |
| Архитектура, хранение, сеть, безопасность или обновление приложения | `systemPatterns.md` |
| Структура, стек, сборка или тестирование | `techContext.md` |
| Реализация, ревью, документация или Git | `developmentWorkflow.md` |
| Версия, публикация или проверка релиза | `releaseProcess.md` |
| Реализованные возможности, ограничения или бэклог | `progress.md` |

Читайте только строки, относящиеся к задаче. Для сложной задачи допустимо
совместить несколько маршрутов.

## Последняя доработка ISBN

- Реализован согласованный порядок РГБ → Open Library → Google Books → кэш.
  После успеха источника дополнений нет; контроль данных локальный, без OpenRouter.
- Добавлены выбор нескольких записей и просмотр применяемых полей; введённые
  значения сохраняются при ошибке и отмене.
- `RslTests` и `OpenLibraryTests` проходят, включая реальный запрос РГБ для
  публичного контрольного ISBN. Основное приложение собрано без ошибок.
- Ручная приёмка новых диалогов остаётся рекомендованной после установки релиза.

## Проверки и блокеры

- Последняя стабильная сборка приложения относится к версии `1.3.0`.
- `BackupTests` проверяют полный состав копии, исключения,
  восстановление, страховочную копию, отказ для старого и
  повреждённого формата и очистку незавершённой копии; все тесты проходят.

- `Build-Release.ps1 -AllowDirty` успешно проверяет updater, состав
  архива, установку и откат для текущих изменений.
- Приложение во время релизной сборки не было запущено.
