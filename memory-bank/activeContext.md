# Активный контекст

Этот файл читается после `AGENTS.md`: здесь актуальное состояние и маршруты.
Код и Git имеют приоритет.

## Маршрут по типу задачи

| Задача | Что прочитать |
|---|---|
| Цель, границы или источник требований | `projectbrief.md` |
| Поведение, пользовательский сценарий или UI | `productContext.md` |
| Архитектура, хранение, сеть, безопасность или обновление приложения | `systemPatterns.md` |
| Структура, стек, сборка или тестирование | `techContext.md` |
| Реализация, ревью, документация или Git | `developmentWorkflow.md` |
| Версия, публикация или проверка релиза | `releaseProcess.md` |
| Реализованные возможности, ограничения или бэклог | `progress.md` |

Читайте только строки, относящиеся к задаче. Для сложной задачи допустимо
совместить несколько маршрутов.

## Последние изменения

- В отчёты добавлен закреплённый подвал «Сумма по строкам» для выдач, книг,
  читателей и дней просрочки. Он отделён от данных, не сортируется и следует
  расположению/видимости колонок; такая же строка добавляется в CSV. Годы и
  номера не суммируются, уникальные итоги статистики не заменяются суммой групп.
  `ReportTotalsTests` — 45 проверок на искусственных данных без показа формы и сети;
  проходят также выбор экземпляров (60), статистика (32), сортировка (130) и основная
  сборка. Ручная проверка подвала остаётся невыполненной. Включено в подготовку версии `1.8.0`.

- Исправлено обновление нижнего списка экземпляров после поиска по содержанию:
  `SetupGrid` сохраняет специальный обработчик выбора книги при смене схемы,
  открытии истории и возврате в каталог. Состав колонок и сведения не менялись.
  Поле поиска по содержанию и «Найти» перенесены в конец верхней панели;
  порядок закреплён независимо от переноса строк и согласован с Tab.
  `BooksSelectionTests` — 60 проверок на временной искусственной базе без сети
  и показа формы; сортировка (130), горячие клавиши (53) и основная сборка проходят.
  Ручная приёмка остаётся невыполненной. Включено в подготовку версии `1.8.0`.

- Исправлено исключение при открытии выбора модели кнопкой «…»: создание native
  handle таблицы во время настройки клавиш вызывало выбор строки до создания
  кнопки «Готово». Событие подключается после создания кнопок, инициализация и
  уничтожение защищены. `CreateModelSelectionForm` наполняет диалог без сети/показа.
  `uTwoLineCombo` разделяет высоту редактируемого поля и двухстрочного списка,
  чтобы поле модели не перекрывало стоимость. `ModelDialogTests` — 19 проверок
  без показа окон и пользовательских данных. Ручная проверка исправления остаётся.

- Добавлен отчёт «Статистика выдач» с включительным календарным периодом,
  представлениями по книгам/категориям, уникальными читателями, общими итогами
  и экспортом CSV с условиями. Сортировка первоначально по числу выдач убывающе,
  раскладки представлений независимы. Используется дата выдачи и текущая категория;
  продления не прибавляются, выдачи удалённых книг сохраняются в статистике.
  `LoanStatisticsTests` — 32 проверки; `GridSortingTests` — 130;
  `RecognitionTests` и основная сборка проходят. Приложение перед сборкой закрыто
  штатно; ручная приёмка интерфейса отчёта не выполнена.

- В настройки добавлены Claude Sonnet 5.5, Claude Opus 5.5 и Gemini 3.8 Flash.
  Список показывает входные/выходные цены USD за миллион токенов, выбранное поле —
  также дату загрузки. Цены обновляются из публичного каталога и доступны из кэша
  без сети; текущая модель и избранное сохраняются.
- Информационный поиск содержит историю запросов с отдельными результатами каждого
  запуска и модели. История хранится для пользователя между сеансами, включается
  в резервные копии, открывается без API; изменённый каталог помечает результат
  как требующий проверки. Явная очистка доступна в «Действия».
  `HistoryModelTests` — 56 изолированных проверок; ещё 4 проверки публичного API
  подтвердили наличие трёх моделей и цен без ключа и платных вызовов.
  `BackupTests`, `RecognitionTests` и `ButtonShortcutsTests` (53) проходят.
  Основное приложение собрано; ручная проверка нового списка и истории не выполнена.

- На вкладке «Книги» добавлен поиск информации через настроенную модель OpenRouter:
  обычные поля фильтруют при вводе и объединяются по «И», нейросеть вызывается
  только по «Найти», F3 или Enter. Один запрос содержит весь локально отобранный
  каталог. Результаты с ранжированием, обоснованием и подтверждённым местом в книге
  показаны в основной таблице; её раскладка отделена от обычного каталога.
  Операции книги перенесены в «Действия», добавление и панель экземпляров сохранены.
  Файловая команда «Каталог для нейросети…» заменена встроенным поиском.
  `BookSearchTests` — 83 проверки, `GridSortingTests` — 130,
  `ButtonShortcutsTests` — 53; `RecognitionTests` проходит.
  Ручная приёмка интерфейса и реальный запрос OpenRouter остаются невыполненными.
  Полные тексты и отдельные оглавления не загружаются.

- Во всех 12 таблицах добавлена настройка порядка и видимости колонок через
  контекстное меню заголовка. Раскладки сохраняются для пользователя, для отчётов —
  отдельно по виду. Общий компонент `uLibraryGrid` сохраняет логические номера
  полей после перестановки; сортировка и редактирование используют эту привязку.
  `GridSortingTests` — 130 проверок, `ButtonShortcutsTests` — 53 проверки;
  сборка основного приложения проходит. Ручная проверка меню и диалога остаётся
  невыполненной.

- Все отчёты на закладке «Отчёты» содержат первую содержательную колонку
  «№ п/п». На экране номера пересчитываются после сортировки; CSV содержит
  нумерацию строк в исходном порядке отчёта.
- Категория в карточке книги поддерживает ввод с автодополнением по нескольким
  буквам без учёта регистра. Для сохранения требуется существующая категория.
- В меню «Действия» раздела «Книги» команда «Скопировать (F9)» открывает новую карточку с
  данными выбранной книги, категорией и обложкой; предлагается свободный
  инвентарный номер. Новая книга и первый экземпляр создаются при сохранении.
- Категория книги обязательна при сохранении; добавлены уточнение выдачи,
  поиск книги по полному инвентарному номеру и категория в таблице выдач.
- В отчёте свободных инвентарных номеров пропуски выводятся диапазонами
  (`1-500`, `510-550`), одиночные номера — отдельно. Экспорт содержит тот же
  формат; сортировка выполняется по числовому началу диапазона.

  публичного контрольного ISBN. Основное приложение собрано без ошибок.
