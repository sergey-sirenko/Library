# Активный контекст

Этот файл читается после `AGENTS.md`: здесь актуальное состояние и маршруты.
Код и Git имеют приоритет.

## Маршрут по типу задачи

| Задача | Что прочитать |
|---|---|
| Цель, границы или источник требований | `projectbrief.md` |
| Поведение, пользовательский сценарий или UI | `productContext.md` |
| Архитектура, хранение, сеть, безопасность или обновление приложения | `systemPatterns.md` |
| Структура, стек, сборка или тестирование | `techContext.md` |
| Реализация, ревью, документация или Git | `developmentWorkflow.md` |
| Версия, публикация или проверка релиза | `releaseProcess.md` |
| Реализованные возможности, ограничения или бэклог | `progress.md` |

Читайте только строки, относящиеся к задаче. Для сложной задачи допустимо
совместить несколько маршрутов.
