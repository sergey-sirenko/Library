# Активный контекст

## Текущее состояние

- Версия исходников и последний стабильный GitHub Release: `1.1.1`.
- Основная ветка: `main`; удалённый репозиторий: `sergey-sirenko/Library`.
- Версия отображается в заголовках окна входа и главного окна.
- Обновления проверяются вручную на вкладке «Настройки» через публичный GitHub
  Releases API.

## Правила текущей работы

- Разработка, проверки и тематические коммиты выполняются локально.
- `push`, теги и GitHub Releases создаются только по явной команде пользователя.
- Если публикуются изменения программы, обязательны новая версия, чистая сборка,
  стабильный Release с ZIP и `.sha256` и проверка `/releases/latest`.
- Документационные изменения можно коммитить локально без новой сборки и релиза.

## Рабочее дерево

После проверки обновления в `Prog/` могут оставаться runtime-файлы
`INSTALL.md`, `Library.exe.old` и локальное изменение установочной инструкции.
Они не относятся к исходникам, не должны автоматически удаляться или попадать
в тематические коммиты.

## Сборка

- Основное приложение: `Library.lpi` → `Prog/Library.exe`.
- Помощник обновления: `LibraryUpdater.lpi` → `Prog/LibraryUpdater.exe`.
- Полная release-проверка: `scripts/Build-Release.ps1` из чистого рабочего дерева.
