# Прогресс

## Сделано
- Техническое задание.
- Memory Bank и `.cursorrules`.
- Ядро: бинарное хранилище, CRC, безопасная запись, индексы, блокировка экземпляра.
- Бизнес-логика: книги, экземпляры, читатели, выдачи, категории, пользователи, настройки.
- Журнал действий, резервное копирование/восстановление, отчёты CSV.
- GUI: вход, главная форма с разделами по ТЗ.
- Сборка `Library.exe` через `lazbuild` успешна.
- Исправлена ложная ошибка блокировки каталога Data при запуске из `Prog`.
- Ручное редактирование колонки «Срок» на вкладке «Выдачи» с сохранением в `Loans.dat` и записью в журнал.
- Перенос длинного текста в ячейках списков и многострочные строки (автовысота при смене ширины колонок).
- Вкладка «Экземпляры» объединена с «Книгами»: нижний список фильтруется по выбранной книге, сплиттер сохраняет высоту списка.
- Добавлен справочник «Места хранения» (`Locations.dat`); экземпляр выбирает место из обязательного справочника.
- Во всех табличных списках включено выделение по ячейкам вместо выделения всей строки.
- Состояние экземпляра выбирается из списка `Плохое` / `Среднее` / `Хорошее`, значение по умолчанию — `Среднее`.
- В нижнем списке экземпляров добавлена колонка «Состояние», кнопка «Добавить экз.» перенесена на панель этого списка.
- На вкладке «Выдачи» добавлен флажок «Только выданные» для отбора открытых выдач.
- UI-настройки сохраняются по пользователям в `UserLayout.cfg`; вход выполняется выбором активного пользователя из списка с запоминанием последнего логина.
- Отчёты отображаются в табличном виде с рамками; сохранение CSV сохранено.
- В полях поиска на вкладках «Книги» и «Читатели» добавлены кнопки очистки `X`.
- На вкладках «Выдачи» и «Просрочки» двойной клик по ячейкам «Инв. №», «Книга» и «Читатель» открывает соответствующие карточки экземпляра, книги и читателя.
- В главной форме иконки закладок и кнопок — картинки из `TImageList` (`uUIIcons.pas`), не Unicode-шрифт; кнопки переведены на `TBitBtn` с `Glyph`.
- У программы есть иконка окна/exe: `resources/Library.ico`, ресурс `MAINICON` в `Library.rc`.
- В списках слева колонка-маркер активной строки (`▶`); после добавления/изменения карточки и операций выдачи строка восстанавливается по ID с фокусом на первой колонке данных.
- Глобальный размер шрифта UI: поле `UIFontSize` в `Settings.dat` (схема NextID≥2), SpinEdit на вкладке «Настройки», применение через `Screen.SystemFont` + пересчёт layout (вход, тулбары, настройки, TabHeight/MultiLine, диалоги).
- Активная закладка разделов (`pcMain`) — коричневая подпись (`ACTIVE_TAB_CAPTION_COLOR`), owner-draw в `uMainForm.pas`.
- В карточке выдачи вместо списка всех читателей — поиск по части ФИО (`IssueLoanDialog`: поле, «Найти», ListBox; пустой запрос = пустой список).
- В `PlaceDialogButtons` сначала задаётся `ClientHeight`, затем якоря кнопок `akBottom` — иначе «Сохранить»/«Отмена» уезжали за нижний край карточки.
- Карточка выдачи: «Найти» у инв. № + надпись названия/предупреждения; `lbReaders.akBottom` только после `PlaceDialogButtons`.
- При ошибке записи карточки (книга, экземпляр, читатель, категория, место, пользователь, выдача) форма остаётся открытой: `PlaceDialogButtons` даёт `mrNone`, запись в хелперах `OKClick`, `ModalResult := mrOK` только при успехе.
- В закладке «Книги» добавлена колонка «Издательство» (после «Автор»); данные берутся из `TBook.Publisher` (поле уже было в БД и в карточке).
- В Категорию добавлен необязательный «Шифр» (расширение ТЗ п. 4.5): допускаются латиница/кириллица/цифры/дефис/точка, без пробелов, уникальность не проверяется. Поле `TCategory.Code`, миграция `Categories.dat` с версии 2 на 3 (`FORMAT_VERSION` поднят до 3), валидация `IsValidCategoryCode`, отдельная колонка в `gridCategories` после «Наименование», поле в `EditCategoryDialog`. Журнал действий пишет шифр в `DetailsBefore/After`.
- В закладке «Отчёты» добавлен вариант «Свободные экземпляры»: `TReportService.AvailableCopies`, фильтр `csAvailable`, сортировка по `InventoryNo`, колонки: Инв.№, Книга, Место хранения, Состояние, Дата поступления.
- В отчёте «Каталог книг» колонка «Категория» переставлена перед «Год» (порядок: Название, Автор, Категория, Год, Издательство, ISBN).
- В настройки добавлено поле «Начало инвентарных номеров» (`TSettings.InventoryStartNo`, дефолт 1): `Settings.dat` мигрирован со схемы 2 на 3 (`NextID=3`), SpinEdit на вкладке «Настройки», сохранение через `UpdateSettings`. При добавлении нового экземпляра (`EditCopyDialog`, `ACopy=nil`) поле «Инв. №» заполняется первым свободным целочисленным номером, начиная с `InventoryStartNo`; если в последовательности есть пропуск — подставляется он, иначе следующий за максимальным. Нечисловые номера вроде «Б-1» при поиске не учитываются.
- На вкладке «Настройки» добавлены поля «Модель OpenRouter» и «OpenRouter API Key» (`TSettings.OpenRouterModel`, `TSettings.OpenRouterApiKey`): `Settings.dat` мигрирован со схемы 3 на 4 (`NextID=4`), два Edit на вкладке, сохранение через `UpdateSettings`.
- На вкладке «Настройки» добавлена кнопка «Тест соединения» (`btnTestOpenRouter`): проверяет ключ и доступность указанной модели через `GET https://openrouter.ai/api/v1/models` (бесплатный, без списания токенов); результат — `mtInformation` с числом моделей и доступностью указанной либо `mtError` с HTTP-кодом и пояснением.
- HTTP-стек для OpenRouter переведён с `fphttpclient`+`opensslsockets` на WinHTTP (модуль `WinHTTP`, SChannel внутри `winhttp.dll`/`schannel.dll` из `System32`). Сторонние DLL (`libssl-1_1-x64.dll`, `libcrypto-1_1-x64.dll`) больше не нужны — `Library.exe` зависит только от `winhttp.dll` и стандартных системных. Внутри `uOpenRouter.pas` появилась обёртка `HttpRequest(Method, Url, ApiKey, Body, out Status, out Response, out Error)` поверх `WinHttpOpen/Connect/OpenRequest/AddRequestHeaders/SendRequest/ReceiveResponse/QueryHeaders/ReadData`. Распознавание обложек (`RecognizeBookImage`) использует ту же обёртку для `POST /api/v1/chat/completions`.
- Сообщения об ошибках OpenRouter/WinHTTP переведены в человеческие формулировки: `WinHttpErrorText` расшифровывает коды WinHTTP (12002 таймаут, 12007 DNS, 12029 сервер недоступен, 12044/12045/12046 сертификаты, 12175 TLS и т.д.), `ExtractOpenRouterErrorMessage` достаёт `error.message` из JSON-ответа `{"error":{"message":…}}`. В `HttpRequest` и вызывающих функциях убраны «Не удалось X (код N)» в пользу конкретных причин (например, «Подключение к серверу openrouter.ai: сервер недоступен или отверг соединение.», «API Key отклонён OpenRouter (HTTP 401): User not found.», «OpenRouter: HTTP 404. No endpoints available matching your guardrail restrictions…»).
- В настройках добавлена кнопка «…» справа от поля «Модель OpenRouter» (`btnSelectOpenRouterModel`): открывает диалог выбора модели из каталога OpenRouter. Новые файлы: `src/uOpenRouterModels.pas` (типы `TModelInfo`/`TModelInfoArray`, `FetchOpenRouterModels`, `SortModelsByPromptPrice` — сортировка по prompt-цене за 1M токенов по возрастанию, отрицательные sentinel-цены уезжают в конец; `FormatModelPrice` выдаёт «бесплатно» / `$X.XX` / «—») и `src/forms/uSelectModelForm.pas` (модальный диалог с фильтром, `TStringGrid` 3 колонки, двойной клик и Enter — OK, Esc — отмена). Текущая модель подсвечивается при открытии.
