# Состояние проекта

## Реализованные подсистемы

### Данные и надёжность

- Бинарное хранилище сущностей, CRC, индексы и безопасная атомарная запись.
- Автоматические внутренние ID, логическое удаление и восстановление.
- Блокировка второго экземпляра, журнал действий и технический журнал.
- Ручные и автоматические резервные копии с проверкой и восстановлением.

### Библиотечная работа

- Книги, экземпляры, категории, места хранения, читатели и пользователи.
- Новая книга создаётся вместе с первым экземпляром; инвентарный номер
  предлагается автоматически, а последнее место хранения запоминается для
  текущего пользователя; повторный ISBN не создаёт новую книгу.
- Выдача, возврат, продление, ограничения и контроль просрочек.
- Отчёты на экране и экспорт CSV, включая каталог и свободные экземпляры.
- Настройки сроков, лимитов, инвентарных номеров, шрифта и OpenRouter.

### Интерфейс

- Русскоязычные формы входа, главная форма и карточки сущностей.
- ISBN расположен первым в карточке книги, получает фокус при открытии и запускает
  заполнение карточки по Enter.
- Поиск, фильтрация, сортировка, раздельный показ удалённых записей и переходы
  между связанными сущностями.
- Пользовательская раскладка интерфейса, глобальный размер шрифта, иконки и
  восстановление выделения строк по ID.
- Табличные отчёты и многострочные ячейки с адаптацией высоты.

### Сеть и обновления

- OpenRouter через WinHTTP/SChannel: проверка соединения, выбор модели и
  распознавание фотографий книг без сторонних SSL DLL.
- Распознавание таблиц и скопированных веб-страниц из TXT через OpenRouter:
  проверка расположения колонок таблицы, выделение библиографических записей,
  автоматические инвентарные номера для веб-копий, ручная проверка всех полей,
  агрегированная статистика использования и массовое сохранение.
- Заполнение карточки книги по ISBN через Open Library с проверкой ISBN-10/ISBN-13,
  предпочтением русских изданий, контекстной нейросетевой локализацией русских
  библиографических данных с сохранением иностранных фрагментов, загрузкой
  обложки и локальным кэшем для повторного офлайн-доступа; после сохранения
  обложка копируется в `Covers`, а в книге хранится её относительное имя.
- При отсутствии книги в Open Library — резервный поиск русскоязычного издания
  через Google Books API с отдельным необязательным API Key.
- Ручная проверка стабильного GitHub Release, загрузка и проверка пакета.
- `LibraryUpdater.exe` с ожиданием завершения приложения, заменой, перезапуском и
  откатом через `Library.exe.old`.

### Проверки и выпуск

- `scripts/Build-Release.ps1` собирает приложение, updater и тестовые проекты,
  проверяет версии, JSON, SHA-256, установку, откат и состав ZIP.
- Стабильные релизы `v1.1.0`, `v1.1.1`, `v1.1.2` и `v1.1.3` опубликованы в GitHub.

## Актуальные ограничения и бэклог

- Нужен полный ручной прогон приёмочных критериев на рабочей машине.
- Выбор файла обложки пока выполняется вводом пути; желателен стандартный диалог.
- Автоматические тесты сосредоточены на updater; основные UI-сценарии проверяются
  сборкой и целевым ручным прогоном.
