# Инструкция: как установить новую версию программы «Библиотека храма»

Эта памятка для человека, который редко работает с компьютером.  
Следуйте шагам по порядку. Ничего сложного: главное — **не удалить папку с данными**.

---

## Что вам нужно

1. Папка, в которой уже работает программа (обычно там лежит файл `Library.exe`).
2. Новая версия программы — файл `Library.exe` (вам его передадут на флешке, по почте или в архиве).
3. Несколько минут времени.

---

## Первая установка (если программы ещё не было)

1. Создайте папку, например: `C:\Libra\Prog`.
2. Положите туда файл `Library.exe`.
3. Запустите `Library.exe` двойным щелчком.
4. Папки `Data`, `Covers`, `Backup`, `Logs` создадутся сами.
5. При первом входе используйте:

   - логин: `admin`
   - пароль: `admin`

Сразу смените пароль администратора в разделе пользователей.

---

*Программа «Библиотека храма» не требует установки через «Программы и компоненты» Windows и не нуждается в интернете.*


## Важно запомнить

| Можно заменять | Нельзя удалять |
|---|---|
| файл `Library.exe` | папку `Data` |
| | папку `Covers` |
| | папку `Backup` |
| | папку `Logs` |

В папке `Data` хранятся все книги, читатели и выдачи.  
Если её удалить — данные пропадут.

---

## Шаг 1. Закройте программу

1. Если программа «Библиотека храма» открыта — закройте её.
2. Нажмите крестик в правом верхнем углу окна.
3. Убедитесь, что программа больше не запущена (её окна нет на экране).

Если программа не закрывается:
- нажмите правой кнопкой мыши по её значку на панели задач внизу экрана;
- выберите «Закрыть окно».

---

## Шаг 2. Сделайте резервную копию (очень желательно)

Лучше перестраховаться перед обновлением.

### Вариант А — через программу (если успели до закрытия)

1. Откройте программу.
2. Перейдите на вкладку **«Резервные копии»**.
3. Нажмите кнопку создания резервной копии.
4. Дождитесь сообщения об успехе.
5. Закройте программу.

### Вариант Б — вручную (если программа уже закрыта)

1. Откройте папку с программой.
2. Найдите папку `Data`.
3. Нажмите по ней правой кнопкой мыши → **«Копировать»**.
4. Перейдите на Рабочий стол.
5. Нажмите правой кнопкой мыши по пустому месту → **«Вставить»**.
6. На Рабочем столе появится копия папки `Data` — её можно оставить до проверки, что всё работает.

---

## Шаг 3. Найдите папку с программой

Обычное расположение:

- `C:\Libra\Prog`
- или другая папка, куда программу положили при первой установке
- иногда ярлык на Рабочем столе ведёт туда же

Как открыть папку через ярлык:

1. Найдите ярлык программы на Рабочем столе.
2. Нажмите по нему **правой** кнопкой мыши.
3. Выберите **«Расположение файла»** (или «Открыть расположение файла»).
4. Откроется нужная папка.

В этой папке вы должны увидеть файл:

```
Library.exe
```

и рядом папки вроде:

```
Data
Backup
Covers
Logs
```

---

## Шаг 4. Замените только файл программы

1. Найдите **новый** файл `Library.exe` (тот, что вам передали).
2. Если новый файл лежит в архиве (`.zip`):
   - нажмите по архиву правой кнопкой мыши;
   - выберите **«Извлечь всё...»** (или «Распаковать»);
   - откройте распакованную папку и найдите `Library.exe`.
3. Скопируйте новый `Library.exe`:
   - правой кнопкой мыши → **«Копировать»**.
4. Перейдите в папку со старой программой.
5. Вставьте файл:
   - правой кнопкой мыши по пустому месту → **«Вставить»**.
6. Windows спросит, заменить ли файл — выберите **«Заменить файл в папке назначения»**.

Готово: обновлена только программа, данные остались на месте.

---

## Шаг 5. Запустите новую версию

1. Дважды щёлкните по `Library.exe`  
   или по ярлыку на Рабочем столе.
2. Войдите в программу как обычно (логин и пароль).
3. Проверьте, что видны ваши книги, читатели и выдачи.

Если всё на месте — обновление прошло успешно.

---

## Если что-то пошло не так

### Программа не запускается

1. Убедитесь, что вы заменили файл именно в той папке, где лежит `Data`.
2. Попробуйте запустить `Library.exe` ещё раз.
3. Если не помогает — обратитесь к тому, кто передал новую версию, и сообщите текст ошибки.

### Данных не видно / папка Data пропала

1. Не паникуйте и ничего больше не удаляйте.
2. Если вы делали копию `Data` на Рабочий стол — скопируйте её обратно в папку с программой и назовите снова `Data`.
3. Если в программе есть вкладка **«Резервные копии»** — можно восстановить данные оттуда.
4. Если сами не уверены — позовите человека, который обслуживает компьютер.

### Случайно удалили старый Library.exe, а новый ещё не вставили

Просто скопируйте новый `Library.exe` в ту же папку.  
Данные при этом не страдают, если папка `Data` на месте.

---

## Краткая шпаргалка

1. Закрыть программу.  
2. Сделать копию папки `Data` (на всякий случай).  
3. Скопировать новый `Library.exe` поверх старого.  
4. **Не трогать** папки `Data`, `Covers`, `Backup`, `Logs`.  
5. Запустить программу и проверить, что данные на месте.
