# Библиотека храма

Настольная информационная система учёта библиотеки храма на Free Pascal / Lazarus.

## Требования

- Lazarus 3.x / 4.x с Free Pascal (только стандартные пакеты LCL / LazUtils / FCL / RTL)
- Windows

## Сборка

1. Откройте `Library.lpi` в Lazarus.
2. Меню **Run → Build** или:

```bat
lazbuild Library.lpi
```

3. Запустите `Library.exe`.

Точка входа: `LibraApp.lpr` (имя `Library` нельзя использовать как идентификатор программы — это ключевое слово Pascal).

## Первый вход

- Логин: `admin`
- Пароль: `admin`

Сразу смените пароль администратора.

## Возможности

- Каталог книг и экземпляров с уникальными инвентарными номерами
- Читатели, выдача / возврат / продление
- Просрочки, отчёты (экран + CSV)
- Категории, пользователи и роли
- Логическое удаление, журнал действий
- Собственные бинарные `.dat` и индексы `.idx`
- Безопасная запись и резервное копирование

## Структура данных

```
Library\
├── Library.exe
├── Data\          — бинарные .dat и индексы .idx
├── Covers\        — обложки книг
├── Backup\        — резервные копии
└── Logs\          — журнал действий и технический журнал
```

Каталоги создаются автоматически при первом запуске.
