# Библиотека

Настольная информационная система учёта библиотеки на Free Pascal / Lazarus.

Текущая версия: **1.8.0**.

## Требования

- Lazarus 3.x / 4.x с Free Pascal и стандартными пакетами LCL, LazUtils, FCL и RTL
- Windows

## Разработка

Работу с репозиторием начинайте с [`AGENTS.md`](AGENTS.md). Структура проекта,
проверенная команда сборки и матрица тестирования находятся в
[`memory-bank/techContext.md`](memory-bank/techContext.md).

## Первый вход

- Логин: `admin`
- Пароль: `admin`

Сразу смените пароль администратора.

## Обновление программы

Администратор может открыть вкладку **«Настройки»** и нажать
**«Проверить обновление»**. Программа проверяет последний стабильный релиз GitHub.
Если доступна новая версия, приложение:

1. скачивает архив и проверяет его размер и SHA-256;
2. проверяет состав архива и создаёт полную резервную копию;
3. закрывается, заменяет `Library.exe` через `LibraryUpdater.exe` и запускается снова.

Папки `Data`, `Covers`, `Backup` и `Logs` при обновлении не заменяются. Предыдущий
исполняемый файл сохраняется рядом под именем `Library.exe.old`.

Версию `1.1.0` пользователям предыдущих сборок нужно установить вручную; начиная
с неё дальнейшие обновления доступны из программы.

## Выпуск новой версии

Канонический процесс сборки, публикации и проверки релиза описан в
[`memory-bank/releaseProcess.md`](memory-bank/releaseProcess.md). Не выполняйте
публикацию только по сокращённому описанию из README.

## Возможности

- Каталог книг и экземпляров с уникальными инвентарными номерами
- Меню «Действия» для книг, копирование по F9 и автодополнение категории
- Читатели, выдача, возврат и продление
- Просрочки, отчёты на экране и экспорт CSV
- Поиск информации в книгах через настроенную нейросеть OpenRouter
- Настройка порядка и видимости колонок во всех таблицах с сохранением для пользователя
- Нумерация строк отчётов и диапазоны свободных инвентарных номеров
- Категории, места хранения, пользователи и роли
- Логическое удаление, журнал действий
- Собственные бинарные `.dat` и индексы `.idx`
- Безопасная запись и резервное копирование
- Заполнение карточки по ISBN через РГБ, Open Library и Google Books
- Ручное обновление через стабильные GitHub Releases

## Статистика выдач

На вкладке **«Отчёты»** выберите **«Статистика выдач»**, задайте даты **«С»** и
**«По»** включительно, выберите **«По книгам»** или **«По категориям»** и нажмите
**«Сформировать»**. По умолчанию выбран период с начала текущего месяца по сегодня.

По книгам показаны название, автор, категория, количество выдач, уникальных
читателей и последняя выдача в периоде. По категориям — количество выдач, разных
книг и уникальных читателей. Самые востребованные стоят первыми; можно сортировать
по любому столбцу. Под условиями показаны общие итоги, а раскладки колонок двух
представлений сохраняются отдельно.

Считаются выдачи по дате оформления, включая уже возвращённые книги; продления
не увеличивают счётчик. Экземпляры одной книги объединяются. Удалённые выдачи
исключаются, а выдачи впоследствии удалённых книг и экземпляров учитываются.
Показываются только книги и категории с выдачами в периоде. Категория берётся
текущая: её изменение задним числом меняет распределение старых выдач.

**«Сохранить CSV»** выгружает период, представление, общие итоги и таблицу.
В отчётах с количественными показателями закреплён подвал **«Сумма по строкам»**:
суммируются выдачи, книги, читатели и дни просрочки. Эта строка также включается
в CSV. Годы, даты, номера строк, ISBN и инвентарные номера не суммируются.
Сумма читателей по группам может учитывать человека несколько раз; общий показатель
уникальных читателей в статистике остаётся отдельным.
После изменения условий требуется снова сформировать отчёт. Если выдачу невозможно
связать с книгой, она не включается в подсчёт и показывается отдельное предупреждение.

## Поиск информации через нейросеть

1. Администратор задаёт модель и OpenRouter API Key на вкладке **«Настройки»**.
2. На вкладке **«Книги»** введите запрос в поле **«Какую информацию найти в книгах»**.
3. При необходимости заполните название/автора/ISBN и инвентарный номер,
   чтобы ограничить набор книг. Все заполненные поля действуют совместно.
4. Нажмите **«Найти»**, F3 или Enter в любом поисковом поле.

В список моделей добавлены Claude Sonnet 5.5, Claude Opus 5.5 и Gemini 3.8 Flash;
ранее выбранная модель и избранное сохраняются. Под ID каждой модели показаны
цены входа и выхода в долларах США за миллион токенов из
[каталога OpenRouter](https://openrouter.ai/api/v1/models). При первом раскрытии
списка за сеанс программа обновляет цены, а без сети использует кэш. Под полем
видна дата загрузки цен; неизвестная цена обозначается отдельно. Кнопка **…**
повторно загружает каталог и открывает подробный выбор моделей.

Обычные поля фильтруют список при вводе. Нейросеть вызывается только по явному
запуску и получает один запрос со всем отобранным каталогом: библиографическими
сведениями, полными описаниями, категориями и сведениями об экземплярах.
Показ удалённых книг учитывается. Ключ передаётся только для авторизации;
данные читателей, выдач и пользователей в запрос не включаются.

Результаты показаны в основной таблице в порядке предполагаемой полезности,
с обоснованием и колонкой «Где искать в книге». Главы и страницы отображаются
только с дословным подтверждением из описания этой книги; иначе — «место не
установлено». Полных текстов и отдельных оглавлений программа не загружает.
Нижний список экземпляров работает при выборе найденной книги.

Изменение любого поля поиска, показа удалённых записей или данных каталога
сбрасывает подборку; для нового обращения снова нажмите «Найти».
Кнопка **X** очищает все три поля. Сортировка и раскладка колонок обычного
каталога сохраняются отдельно от подборки нейросети.

Поле информационного запроса содержит выпадающую историю. Каждый успешный запуск,
включая поиск без совпадений, сохраняется отдельно с запросом, моделью, датой,
обычными фильтрами и результатами. Одинаковые запросы к разным моделям остаются
отдельными записями. Выбор записи мышью или Enter в раскрытом списке восстанавливает
подборку без обращения к нейросети и без смены настроенной модели. Enter при закрытом
списке запускает новый поиск.

История сохраняется для текущего пользователя между запусками и входит в резервную
копию. После изменения каталога сохранённая подборка помечается как требующая
проверки; отсутствующие книги не показываются, исходные результаты остаются в истории.
Для удаления всех записей используйте **«Действия → Очистить историю поиска…»**.
Кнопка **X** очищает поля и текущую подборку, сохраняя историю.

Во время запроса показано окно ожидания. Отмена запрещает применение ответа;
окно закроется после завершения текущего сетевого вызова. Для сетевых операций
установлен таймаут 60 секунд. При ошибке предыдущий список и поля сохраняются.
Если каталог превышает контекст модели, сузьте обычный отбор или выберите другую
модель. Автоматических повторов и скрытого обрезания каталога нет.

Операции с книгой доступны через **«Действия»**: изменение (F2), копирование (F9),
удаление (Del), восстановление и распознавание изображений/текста. Добавление
(Ins) остаётся отдельной кнопкой. Del в поисковом поле удаляет текст.

## Структура данных

```text
Library\
├── Library.exe
├── Data\          — бинарные .dat, индексы .idx и история поиска .json
├── Covers\        — обложки книг
├── Backup\        — резервные копии
└── Logs\          — журнал действий и технический журнал
```

Каталоги создаются автоматически при первом запуске.
